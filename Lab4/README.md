## Description
This project is a registration form that collects student information and dynamically creates profile cards along with a summary table.

### Features
- Accessible form with semantic HTML and CSS
- Inline validation and error messages
- JavaScript DOM manipulation to create profile cards
- Summary table updates automatically
- Remove button deletes both card and table row
